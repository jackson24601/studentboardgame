# Student Board Game - Shoots and Ladders

A web-based educational review game based on the classic Shoots and Ladders (Snakes and Ladders) board game.

## Quick Start

Simply open `index.html` in your web browser to play!

## Features

- 1-4 team support
- Random turn order
- Two six-sided dice rolling
- Classic 100-square board
- Snakes that slide you down
- Ladders that move you up
- Animated gameplay

## How to Play

1. Select number of teams (1-4)
2. Click "Start Game"
3. Click "Roll Dice" on each turn
4. First team to reach square 100 wins!

For detailed documentation, see [GAME_README.md](GAME_README.md).
